## The Gist

**Claude Code** (IDE extension, what you have now) is excellent for coding. **Hermes** (autonomous agent) is excellent for learning from repeated patterns and improving skills over time.

**Path A** (recommended): Add memory synthesis + skill learnings to Claude Code. Takes 2 hours, uses only markdown files, no new dependencies.

**Path B** (later): Run Hermes in parallel for autonomous skill improvement. Consider in Ex5+ when extraction pipeline produces lots of trial-and-error data.
