## Key Learnings
- Completion defined by tests + API responses misses user-facing gaps. Both Compare UX and Upload CV were "done" by test criteria but unusable from a browser.
- Each exercise that adds a backend feature should explicitly scope the corresponding frontend surface at planning time.
- The Compare URL-param design was correct for Ex1 static IDs but became unusable when Ex3 introduced dynamic hex IDs — transition wasn't reviewed.
- Auth token in React state only = every new tab is a login wall. localStorage persistence is the minimum viable UX.
- `docker compose` (space, V2) not `docker-compose` (hyphen, legacy deprecated).
